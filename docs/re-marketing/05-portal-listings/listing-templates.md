> **Version:** 1.0
> **Platform:** Bayut (primary), Property Finder (secondary)
> **Brand Voice:** Professional, informative, differentiated. Avoid typical agent hype.

---

## Purpose

Ready-to-use listing description templates for Dubai property portals. Each template highlights WTP's unique value: integrated RE + corporate + banking advisory, not just property sales.

**Words to USE:** Golden Visa eligible, banking pre-screen, investment advisory, ownership structure, integrated service, bankable structure, compliance-first
**Words to AVOID:** Guaranteed ROI, cheapest, "call now!!!", offshore, amazing views!, must see!, incredible!, unbelievable!, exclamation marks

**SEO for Portals (Bayut/Property Finder search):**
- Title format: `[Property Type] in [Area] — [Key Feature]` (e.g., "2BR Apartment in Dubai Marina — Golden Visa Eligible")
- Include area name, bedroom count, and "Golden Visa" or "Investment" in first 20 words
- Include price range bracket in description (portals filter by price)
- Tag all relevant features in portal fields: Golden Visa, Beach Access, Metro Nearby, etc.

**Listing Quality Checklist (per listing):**
- [ ] 10+ high-quality photos (professional, consistent lighting)
- [ ] Floor plan included
- [ ] Video tour for properties 5M+ AED
- [ ] 3D tour for properties 10M+ AED
- [ ] Price is competitive (check comparable listings on same portal)
- [ ] All portal fields filled (size, view, amenities, parking)
- [ ] Response time SLA: 15 min during business hours
