## Next-Batch Learnings (institutional)

1. **V2 reframe hook discipline = new constitution baseline.** "X is backwards" / "X is not Y" / "X decides" beats "$X lost". Adopt as default hook rule.
2. **V2 CTA lead-magnet specificity = new baseline.** "We send the SOF document list today" > V1's interchangeable "We'll send the diagnostic form".
3. **V1 consequence-stakes survive on persona-of-loss reels.** Visa, banking-permanence, last-will — where the failure mode IS the product. Don't reframe to positive (Exec-Communicator was right on #11).
4. **Claim-verification protocol now mandatory before "CLEAN" status.** Three material legal errors slipped V2's verification gate. Add Phase 1.4 citation pass: every named statute, threshold, numeric anchor must cite primary source. ~2 hr per 20-reel batch.
5. **Two-variant-then-cherry-pick = right production pattern.** Cost a second pass; produced clearly better output than either single variant. Codify as default for high-stakes copy batches (landings, ads, decks).
