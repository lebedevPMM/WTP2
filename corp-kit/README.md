# WTP Corp Kit

Комплект носителей по корпоративным услугам WTP, собранный из пяти скриптов продаж Сергея
(ветка «Корп. Услуги» чата WTP Marketing, июль 2026) + стратегического слоя из той же переписки.

Стиль — канон **сателлитных лендингов WTP** (снят с re.wtp.ae, тот же предок, что `broker-9010/`):
светлая editorial-эстетика, Playfair Display / Inter / JetBrains Mono, контейнер 1120px,
тёмная CTA-секция и тёмный футер. Это **не** стиль основного сайта.

## Рендер

```bash
cd "$HOME/Library/Mobile Documents/com~apple~CloudDocs/Desktop/Antygravity folder/sync/WTP2"
node corp-kit/render.cjs            # всё
node corp-kit/render.cjs landings   # лендинги RU и EN, fullPage PNG
node corp-kit/render.cjs decks      # деки: PNG постранично + PDF 1600×900
node corp-kit/render.cjs ig         # карусели 1080×1350
```

Результат в `corp-kit/render/`. Деки в PDF — `WTP-b2b.pdf`, `WTP-b2c.pdf`,
`WTP-b2b-en.pdf`, `WTP-b2c-en.pdf` в `render/decks/`. EN-лендинги в `render/landings/en-*.png`.

## Проверки

```bash
node corp-kit/_overflow-check.cjs   # переполнение слайдов дек
node corp-kit/_ig-overflow.cjs      # переполнение кадров Instagram
```

Запускать после любой правки текста в деках и каруселях — формат фиксированный,
и лишние две строки уезжают под колонтитул.

## Локальный просмотр

```bash
python3 -m http.server 4173 --directory corp-kit
```

Дальше `http://localhost:4173/landings/` — хаб со всеми пятью услугами.

## Правило работы с текстом

**Ни одна цифра и ни одно утверждение не попадает на публичный носитель, если его нет
в `FACT-LEDGER.md`.** Ledger собран из скриптов с указанием источника и отдельно помечает,
что является внутренним и наружу не идёт (внутренние показатели, план департамента,
цели по партнёрской сети, планы по географии).

Терминология и запрещённая лексика — в `glossary.md`. После любой правки английского
текста прогонять `translation-qa` и дописывать результат в лог прогонов в конце глоссария.

Перед публикацией сверяться с блоком «Открытые вопросы к владельцу» в конце ledger.

## Что осталось до публикации

| # | Блокер | Почему |
|---|---|---|
| 1 | **Юрлицо и номер лицензии в футере** | Сейчас нейтральная строка «WTP · Корп. услуги · Dubai, UAE». Точное юрлицо для корп. услуг (Ilegal!) в репозитории не подтверждено — выдумывать юрлицо на клиентской странице нельзя |
| 2 | **Гарантия возврата по банковским счетам** (Q2) | Опубликована в условной формулировке с перечнем исключений. Нужно подтверждение владельца, что публикуем вообще и что перечень исключений точен |
| 3 | **Домены** (Q3) | Канон сателлитов — сабдомены `*.wtp.ae`. Решение по адресам не принято |
| 4 | **Instagram-аккаунт** (Q4) | Сергей предлагает один общий на все услуги; какой именно — не выбран |
